# 使用说明

> 适用版本：0.1.0（2026-10-24）

## 一、它是干什么的

一台 DSH 接了多个 IM 账号，每个号背后是不同的人。默认所有人都吃同一份 `AGENTS.md`。这个插件让每个号有自己的一份人设，记忆却只有一份。

它站在 im-connect **前面**：插件负责把工作区里的骨架准备好，你去 im-connect 把账号的工作目录指过来。插件不改 im-connect 的任何配置。

## 二、安装

在 DSH 的 **插件市场 → 已安装**里填这份包的本地路径（或者 `link:<绝对路径>`），装好后重启一次 DSH。

启动日志里出现这一行就是装对了：

```
[im-idmanagement] 已就绪：/api/dsh-im-idmanagement/
```

## 三、找到页面

插件页面挂在宿主的 web 端口上，**端口每次启动会变**。三个办法：

1. 用浏览器桥的固定端口：`http://127.0.0.1:3080/api/dsh-im-idmanagement/`
2. 双击 `工具\找端口.cmd`（会自己探出当前端口）
3. 自己查：

   ```powershell
   Get-NetTCPConnection -State Listen |
     Where-Object { (Get-Process -Id $_.OwningProcess).ProcessName -eq 'DeepSeek Harness' } |
     Select-Object LocalPort, OwningProcess -Unique
   ```

## 四、第一次配置

**第一步：选根目录**

- 下拉里是你 DSH 的工作区，选一个；或者直接填一个绝对路径。
- 人设和记忆都建在这个根目录下面。

**记忆放在哪**

- 默认是 `<根目录>\记忆`。
- 你自己的记忆文件夹要是叫别的名字（`笔记`、`备忘`、`docs`……），填进去就用你的。
- 存在就直接用，不存在会给你建一个。
- 徽章显示「默认 / 自定义」，想回去点「恢复默认」。

**第二步：新建人设**

| 填什么 | 含义 |
|---|---|
| 名字 | 也是文件夹名，`IM用户设定\<名字>\` |
| bot 对他的称呼 | 第一句怎么叫，比如「妈咪」 |
| 人设规则 | 分寸、禁忌、能聊什么，写进文件的「人设规则」一节 |

名字里不能有 `\ / : * ? " < > |`，也不能是 `.` 或 `..`。

## 五、生成之后

磁盘上会多出：

```
<根目录>\IM用户设定\
├─ README.md              这套怎么用（第一次生成时写）
└─ <名字>\AGENTS.md       人设模板，可以改
<根目录>\记忆\收件箱.md    流水账
<根目录>\AGENTS.md         末尾多一块带标记的提醒（仅当文件已存在）
```

**最后一步在 DSH 里**：**设置 → IM 助理**，把那个账号的「工作目录」填成页面上复制出来的路径。

> 改工作目录会让该账号当前的会话重建一条（旧会话还在列表里，不会删）。这是 DSH 的正常行为。

## 六、日常用法

- **编辑**：列表里点「编辑」，页面下方展开文本域，改完「保存」。写回的就是那个 `AGENTS.md`。
- **复制路径**：粘贴到 IM 助理的工作目录里。
- **删除**：挪进回收站，不是真删。
- **回收站**：显示占用与每份大小；按「保留 7 天 / 最多 20 份」自动清理，也可以手动「清空回收站」。

回收站位置：`<根目录>\.dsh-im-idmanagement-trash\<时间戳>-<名字>`。想找回，整份挪回 `IM用户设定\` 即可。

## 七、验证

让那个账号的人发一句「在吗」，看回复第一句是不是你设的称呼。

不对就检查两处：

1. 那个账号的工作目录是不是真的指到了 `IM用户设定\<名字>`；
2. 那份 `AGENTS.md` 第一行是不是「本框的规矩优先于外层那份」。

## 八、卸载

1. 插件市场里卸载，或从 `profiles\desktop\package.json` 的 bundles 里删掉 `dsh-im-idmanagement`；
2. 删掉 `node_modules\dsh-im-idmanagement`；
3. 重启 DSH；
4. `IM用户设定\` 和 `记忆\` 是你自己的文件，插件不会删；根 `AGENTS.md` 里那块带标记的文字可以手动删，删了不影响功能。

## 九、常见问题

**页面 404**：插件没加载。看启动日志有没有「已就绪」，以及 bundles 里有没有加。

**生成了但称呼不对**：九成是工作目录没指对。确认后让它再发一句。

**刷新后下拉框空了**：现在会把已保存的根目录回填到下拉/输入框；如果它不在工作区列表里，会填进输入框。

**模板里还有 `{{xxx}}`**：说明宿主还在跑旧代码，重启一次。
